## 技术架构

### 系统组件
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   TLS Client    │    │  TEE Provider   │    │   TLS Server    │
│                 │    │                 │    │                 │
│ • 证书链加载    │    │ • 私钥管理      │    │ • 标准TLS服务   │
│ • TLS握手       │◄──►│ • 签名操作      │    │ • 证书验证      │
│ • 数据传输      │    │ • 验证操作      │    │ • 双向认证      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 安全特性
- **私钥隔离**: 私钥仅在TEE Provider内部操作
- **标准兼容**: 完全兼容OpenSSL TLS协议栈
- **双向认证**: 客户端和服务器互相验证身份
- **证书链**: 支持多级证书信任链

## 文件结构

### 源代码文件
```
src/
├── tee_provider_simple.c    - TEE Provider核心实现
├── tls_client_simple.c      - TLS客户端实现
└── tls_server.c              - TLS服务器实现
```

### 构建文件
```
build/
├── libtee_provider.so       - TEE Provider动态库(未使用)
├── tls_client_simple        - TLS客户端可执行文件
└── tls_server               - TLS服务器可执行文件
```

### 证书文件
```
certs/
├── ca-cert.pem              - 根CA证书
├── ca-key.pem               - 根CA私钥
├── server-cert.pem          - 服务器证书
├── server-key-nopass.pem    - 服务器私钥
├── device-cert.pem          - 设备证书
├── device-key-nopass.pem    - 设备私钥(TEE Provider使用)
└── device-chain.pem         - 完整证书链
```

## 运行说明

### 环境要求
- Ubuntu 18.04+ 或其他Linux发行版
- OpenSSL 3.0+ 
- GCC编译器
- make工具

### 快速运行
```bash
# 1. 安装依赖
sudo ./install_deps.sh

# 2. 编译项目
make all

# 3. 生成证书
make certs

# 4. 启动服务器（新终端）
make test-server

# 5. 运行客户端（另一个终端）
make test-client
```

### 完整演示
```bash
# 一键运行完整演示
./run_demo.sh
```
